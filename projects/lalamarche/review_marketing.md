# ララマルシェ リール講評（marketing-psychology）

目的：地域の家族・幅広い世代に「12/13にララマルシェへ行こう」と思ってもらい、Instagramをフォローしてもらう。
前提：誠実な範囲でのみ使う（作った希少性・事実でない数字は使わない）。

## 良い点
| 心理の考え方 | 今の動画で効いているところ |
|---|---|
| 終わり方の印象（ピーク・エンドの法則） | 最後に日付・入場無料・アカウント名がまとまり、記憶に残る締めになっている |
| 行動は1つに絞る（ヒックの法則） | 最後のお願いが「フォロー」だけで迷わせない |
| 仲間意識（ユニティ） | 「みんなのマルシェ」「どなたでも」で、自分も行っていい場所だと感じられる |
| 本物の目新しさ | 「結婚式場で初開催」は事実で、作った希少性ではない |

## 改善点（効果が大きい順）
1. **最初の1秒でつかむ（注意を引く／続きが気になる効果）**
   リールは1〜2秒で飛ばされる。今の冒頭は静かな「LA LA CHANCE BELAMI」で、何の動画か分からない。
   → 最初の1秒に「結婚式場で、マルシェ!?」のような意外性のある一言を出す（事実なので誠実）。
2. **「無料」をもっと早く大きく（無料の特別な引力）**
   「入場無料」は心理的にとても強い言葉だが、今は16秒すぎまで出てこない。
   → タイトルの場面か表紙で先に見せる。
3. **当日の楽しみ方を思い浮かべてもらう（思い浮かべやすさ／何をしに行くか）**
   人は具体的に想像できる予定に行く。企画書にある「チャペルでブーケづくり体験・フォトスポット／ステージ／グルメ」の3つを一瞬見せると、家族で過ごす1日が想像しやすい。
   ※出店内容は未定のため、主催者が用意する3つのブースの種類だけ。入れるかは要確認。
4. **行くまでの手間を減らす（行動のハードルを下げる）**
   家族連れには「車で行ける？」が壁になる。企画書の「駐車場あり（約80台）」を小さく添えると安心につながる。要確認。
5. **にぎわいの手がかり（みんなが行く効果）**
   ポスターにある「約30店舗予定」は事実の数字で、規模感が伝わる。「来場見込み1,000名」は予測なので使わない。要確認。
6. **何度も目にしてもらう（接触の回数）**
   リール1本で来場を決める人は少ない。表紙をポスターと同じ見た目にそろえると、投稿を見るたびに「あのマルシェだ」と結びつく。
   → 今回、表紙画像を作成（canvas-design）。

## やらないこと
- 「残りわずか」「急いで」など、事実でない急かし方
- 予測の来場者数を実績のように見せること
